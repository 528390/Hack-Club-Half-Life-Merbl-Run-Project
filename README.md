A 3D-Printed Marble Run 🎱

About the Project:
For Hack Club Half Life Week 2, I'm designing a custom 3D-printed marble run using Onshape along with some measurements taken from the guide. My goal is to create a course with different sections that allow a marble to travel through the track smoothly without too much issues occurring.

Design Process:
With Onshape, I designed a base, angled tracks, a Plinko section, a staircase section, a funnel, a tower, and a marble. I used various CAD tools in Onshape, including sketches, extrudes, fillets, chamfers, offsets, sweeps, mirror, arc tangents, and revolves, to create the different components. While designing the components, I decided to adjust the original measurements from the guide for various parts, like the funnel and staircase, because they didn't give me the appearance I wanted. By adjusting the values, the appearance came out like I wanted.
